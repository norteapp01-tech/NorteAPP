# Referências visuais do Norte

Esta pasta é a biblioteca de referência dos layouts definidos para o aplicativo. As imagens ficam separadas por área para facilitar implementação, revisão e comparação visual.

## Regra de uso

- As pastas por área contêm as referências escolhidas para implementação.
- `propostas/` contém alternativas ainda não aprovadas e não deve ser usada como referência final.
- Uma imagem aprovada só deve ser substituída depois de uma nova decisão de design.
- Os arquivos são documentação visual; não são assets carregados pelo aplicativo em produção.

## Convenção de nomes

Os nomes descrevem a função da tela em português, sempre em minúsculas e separados por hífen. Novas referências devem seguir o mesmo padrão.
